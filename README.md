# 필사의 노력 · AI 손글씨 코치

방안지에 필사한 사진 한 장으로 손글씨를 7가지 지표로 진단하고, 다음 한 걸음 처방과 인증서를 받는 무료 웹앱이에요.

**바로 쓰기 → https://jeongdawoont-star.github.io/pilsa/**

## 할 수 있는 것

- **채점·인증**: 사진을 찍거나 고르면 AI가 기준선, 자모 짜임새, 크기 일관성, 받침 균형, 정렬과 자간, 가독성, 정확성을 진단해요.
- **일괄 채점**: 복합기로 스캔한 학급 PDF를 넣으면 번호순으로 채점하고 결과표(엑셀)와 학생별 인증서 ZIP을 만들어요.
- **방안지 출력**: 오늘의 문장을 담은 5mm 방안지를 인쇄해요.
- **글씨 노하우·동기부여·순위**: 바른 글씨 원리와 학급 순위를 보여 줘요.
- **홈 화면 설치**: 휴대폰·태블릿·크롬북에서 앱처럼 설치할 수 있어요(PWA).

## 시작하기

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 Gemini API 키를 만들어요.
2. 앱의 [설정] 탭에 붙여 넣고 저장해요.
3. 키가 없어도 첫 화면의 예시 3장으로 결과 화면을 체험할 수 있어요.

## 개인정보

서버가 없는 앱이에요. 키·이름·점수는 사용하는 브라우저에만 저장되고, 사진은 채점할 때만 Google Gemini로 바로 전송돼요. 자세한 내용은 [개인정보처리방침](privacy.html)과 [이용약관](terms.html)을 확인해 주세요.
